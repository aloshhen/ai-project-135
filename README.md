## 📋 План разработки

1. Создать базовую структуру HTML (index.html) с основными разделами: главная страница, гайды для новичков, калькулятор сборки героев.  
2. Разработать мрачный и атмосферный дизайн с использованием CSS (dark-theme.css).  
3. Добавить интерактивный калькулятор сборки героев с использованием JavaScript (main.js).  
4. Подготовить контент для гайдов (beginner-guides.html) и интегрировать его в структуру сайта.  
5. Оптимизировать изображения и видео для быстрой загрузки (папка assets).  
6. Протестировать сайт на кросс-браузерность и адаптивность.  
7. Запустить сайт и добавить аналитику для отслеживания пользователей.
